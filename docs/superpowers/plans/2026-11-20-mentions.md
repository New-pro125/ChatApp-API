# Message Mentions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Resolve `@username` tokens in cloud direct-chat text messages to chat members, persist one mention row per `(chat, message, mentioned user)` with read state, expose a caller-scoped inbox with unread count and single/bulk mark-read, and project mention summaries into message views — without push notifications or new error codes.

**Architecture:** A normal `message_mentions` table carries `read_at`/`deleted_at`; a `MentionRepository` port with a Drizzle/Postgres implementation is driven by a `MentionService` that parses names, resolves them through a core `UsernameReader` port published by auth, and filters by chat membership. `MessageService` calls sync on text send/edit/forward and hide on delete; `SelfDestructCleanupWorker` hides before scrubbing. A request-scoped `MentionController` serves three `DocumentedRouter` routes, and `MessagePresenter` gains batched mention summaries.

**Tech Stack:** Node 24, TypeScript 7.0.2, ESM (`@/` aliases, explicit `.js` extensions), Express 5, Inversify 8 child containers, Drizzle ORM + PostgreSQL 18, Zod, Vitest + Supertest, Biome.

**Spec:** `docs/superpowers/specs/2026-11-20-mentions-design.md`

## Global Constraints

- One row per `(chat_id, message_id, mentioned_user_id)`, named `message_mentions_chat_message_user_unique`. `chat_id` is mandatory because message ids are unique only within a chat.
- Resolve usernames case-insensitively against chat members with `leftAt === null`. Unknown, non-member, malformed, self, and email/URL-like tokens follow the rules in the spec: unknown/non-member/malformed stay plain text; self-mentions are allowed; email/URL tokens are not parsed.
- Mention parser token grammar: `@` + letter + 4–31 letters/digits/underscores, preceded by start-of-body or a non-word, non-`@`, non-`/`, non-`.` character. Return unique lowercased names only.
- Sync on text send, edit, and forward (only when the resulting message is `type: 'text'`). On edit: insert new targets, retain existing rows (preserve `read_at`), hard-delete removed targets. `deleted_at` is used only for message delete/expiry.
- Hide on explicit delete and self-destruct expiry; hide is idempotent. A sync failure is logged and must never fail an already-stored message; inbox/mark-read failures propagate normally.
- Inbox: `GET /api/chats/mentions?limit&cursor` with `limit` 1–100 (default 30), keyset by uuidv7 `id` descending, `data: { unreadCount, mentions }`, `meta.pagination.nextCursor`. No message body in any mention response.
- Mark-read: `POST /api/chats/mentions/:mentionId/read` returns `200 { id, readAt }` and `404 NOT_FOUND` for unknown/foreign/hidden ids; `POST /api/chats/mentions/read` accepts `{ mentionIds }` with 1–100 uuids, de-duplicates, silently ignores unknown/foreign/hidden ids, and returns `200 { marked }`.
- Message views gain `mentions: [{ userId, username, displayName }]`, hydrated with one batched repository call and one `findSummaries` call per response. No per-message N+1 lookup.
- The inbox's `mentionedBy` is the **message sender**, resolved by joining mention rows to `messages.senderId`; the message-view `mentions` array is the **mentioned users**. Keep these directions distinct: the inbox shows who wrote the message, history shows who was mentioned.
- No new error codes, `ErrorMapper` entries, auth schemes, configuration values, or `.env.example` changes. Reuse `VALIDATION_ERROR`, `UNAUTHORIZED`, `EMAIL_NOT_VERIFIED`, `NOT_FOUND`, and `RATE_LIMITED`.
- All JSON through injected `ApiResponse`; controllers never call `res.json`. Services depend on ports; no Express types, HTTP statuses, or Drizzle types in domain/data service layers. Every relative ESM import uses `.js`; use `@/...` aliases; Biome single quotes, semicolons, trailing commas, 2-space indentation, 100-character lines, organized imports; prefer `unknown` over `any`.
- Use migration `0022` (next after drafts at `0021`); never edit an applied migration. Review generated SQL and finish with `npm run db:check` reporting `Everything's fine 🐶🔥`.
- `plan.md` is gitignored and must stay untracked. This plan and the spec are also gitignored Markdown and must be force-added when committed. Never commit `.env`, secrets, tokens, or real credentials.
- The original checkout has unrelated committed edits to `tests/unit/is-prime.test.ts` and `tsconfig.json` that cause Biome lint to fail; verify per gate there (`npm run typecheck`, `npm run build`, `npx vitest run`, `npx biome check` on changed files) unless those edits are set aside. Definition of done: all gates green, live HTTP smoke with success and error paths, temporary users removed, API stopped.

## Review Focus

- **Non-member or unknown `@username` leaks existence or creates an unusable inbox row** → Task 4 unit test `resolves only resolved names that belong to the chat` and Task 6 HTTP test `keeps unknown and non-member names as plain text`.
- **Read state silently lost when a message is edited** → Task 3 repository test `sync retains retained rows and hard-deletes removed rows` and Task 6 HTTP test `preserves read state for a retained mention across edits`.
- **Another user can read or mark a mention they do not own** → Task 3 test `keysets by id and enforces caller scope` and Task 6 test `returns 404 for another user mention and 400 for invalid input`.
- **Inbox `mentionedBy` points at the mentioned user instead of the sender** → Task 3 repository assertion on `mentionedByUserId` and Task 6 HTTP test `lists a caller-scoped inbox with unread count and keyset paging`.
- **`@` in email addresses or URLs creates false mentions** → Task 4 unit test `ignores email-like and URL-like tokens` plus the dedupe/case tests.
- **Self-destruct expiry leaves a stale inbox entry** → Task 5 integration test `hides mentions when a message is deleted or scrubbed`.

```ts
/**
 * Mentions of chat members in cloud text messages. `chat_id` is part of the
 * key because message ids are unique only within a chat. `deleted_at` hides a
 * mention when its message is deleted or scrubbed; edit removals hard-delete
 * so the unique key never blocks a later re-mention.
 */
export const messageMentions = pgTable(
  'message_mentions',
  {
    id: uuid('id').notNull().default(sql`uuidv7()`),
    chatId: uuid('chat_id')
      .notNull()
      .references(() => chats.id, { onDelete: 'cascade' }),
    messageId: uuid('message_id').notNull(),
    mentionedUserId: uuid('mentioned_user_id')
      .notNull()
      .references(() => users.id, { onDelete: 'cascade' }),
    createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
    readAt: timestamp('read_at', { withTimezone: true }),
    deletedAt: timestamp('deleted_at', { withTimezone: true }),
  },
  (table) => [
    primaryKey({ columns: [table.id], name: 'message_mentions_pkey' }),
    uniqueIndex('message_mentions_chat_message_user_unique').on(
      table.chatId,
      table.messageId,
      table.mentionedUserId,
    ),
    index('message_mentions_user_inbox_idx')
      .on(table.mentionedUserId, table.id.desc())
      .where(sql`${table.deletedAt} is null`),
    index('message_mentions_user_unread_idx')
      .on(table.mentionedUserId, table.id.desc())
      .where(sql`${table.deletedAt} is null and ${table.readAt} is null`),
    foreignKey({
      columns: [table.chatId, table.messageId],
      foreignColumns: [messages.chatId, messages.id],
      name: 'message_mentions_message_fk',
    }).onDelete('cascade'),
  ],
);
```

```ts
import { and, desc, eq, inArray, isNull, lt, sql } from 'drizzle-orm';
import { inject, injectable } from 'inversify';
import { CORE_TYPES } from '@/core/container/core.types.js';
import type { AppDatabase } from '@/core/database/database.provider.js';
import { messageMentions, messages } from '@/core/database/schema/index.js';
import { PersistenceException } from '@/core/errors/repository.error.js';
import {
  mentionSelection,
  MessageMentionMapper,
} from '@/modules/messages/data/message-mention.mapper.js';
import type { MessageMentionRecord } from '@/modules/messages/logic/entities/message-mention-record.js';
import type {
  ListMentionsQuery,
  MessageMentionRepository,
} from '@/modules/messages/logic/ports/message-mention.repository.js';

@injectable()
export class PostgresMessageMentionRepository implements MessageMentionRepository {
  private readonly mapper = new MessageMentionMapper();

  constructor(@inject(CORE_TYPES.Db) private readonly db: AppDatabase) {}

  async sync(
    chatId: string,
    messageId: string,
    userIds: readonly string[],
    now: Date,
  ): Promise<void> {
    try {
      await this.db.transaction(async (tx) => {
        const existing = await tx
          .select({ id: messageMentions.id, userId: messageMentions.mentionedUserId })
          .from(messageMentions)
          .where(
            and(
              eq(messageMentions.chatId, chatId),
              eq(messageMentions.messageId, messageId),
            ),
          );

        const desired = new Set(userIds);
        const stale = existing.filter((row) => !desired.has(row.userId)).map((row) => row.id);

        if (stale.length > 0) {
          await tx.delete(messageMentions).where(inArray(messageMentions.id, stale));
        }

        const present = new Set(
          existing.filter((row) => desired.has(row.userId)).map((row) => row.userId),
        );
        const missing = [...desired].filter((userId) => !present.has(userId));

        if (missing.length > 0) {
          await tx
            .insert(messageMentions)
            .values(
              missing.map((userId) => ({
                chatId,
                messageId,
                mentionedUserId: userId,
                createdAt: now,
              })),
            )
            .onConflictDoNothing({
              target: [
                messageMentions.chatId,
                messageMentions.messageId,
                messageMentions.mentionedUserId,
              ],
            });
        }
      });
    } catch (error) {
      throw new PersistenceException('Failed to sync message mentions', { cause: error });
    }
  }

  async hideForMessage(chatId: string, messageId: string, now: Date): Promise<void> {
    try {
      await this.db
        .update(messageMentions)
        .set({ deletedAt: now })
        .where(
          and(
            eq(messageMentions.chatId, chatId),
            eq(messageMentions.messageId, messageId),
            isNull(messageMentions.deletedAt),
          ),
        );
    } catch (error) {
      throw new PersistenceException('Failed to hide message mentions', { cause: error });
    }
  }

  async listForMessages(
    chatId: string,
    messageIds: readonly string[],
  ): Promise<Map<string, MessageMentionRecord[]>> {
    const result = new Map<string, MessageMentionRecord[]>();

    if (messageIds.length === 0) {
      return result;
    }

    try {
      const rows = await this.db
        .select(mentionSelection)
        .from(messageMentions)
        .innerJoin(
          messages,
          and(
            eq(messages.chatId, messageMentions.chatId),
            eq(messages.id, messageMentions.messageId),
          ),
        )
        .where(
          and(
            eq(messageMentions.chatId, chatId),
            inArray(messageMentions.messageId, [...messageIds]),
            isNull(messageMentions.deletedAt),
          ),
        )
        .orderBy(messageMentions.createdAt);

      for (const row of rows) {
        const group = result.get(row.messageId) ?? [];
        group.push(this.mapper.toRecord(row));
        result.set(row.messageId, group);
      }

      return result;
    } catch (error) {
      throw new PersistenceException('Failed to list message mentions', { cause: error });
    }
  }

  async list(userId: string, query: ListMentionsQuery): Promise<MessageMentionRecord[]> {
    try {
      const rows = await this.db
        .select(mentionSelection)
        .from(messageMentions)
        .innerJoin(
          messages,
          and(
            eq(messages.chatId, messageMentions.chatId),
            eq(messages.id, messageMentions.messageId),
          ),
        )
        .where(
          and(
            eq(messageMentions.mentionedUserId, userId),
            isNull(messageMentions.deletedAt),
            query.beforeId === undefined ? undefined : lt(messageMentions.id, query.beforeId),
          ),
        )
        .orderBy(desc(messageMentions.id))
        .limit(query.limit);

      return rows.map((row) => this.mapper.toRecord(row));
    } catch (error) {
      throw new PersistenceException('Failed to list mentions', { cause: error });
    }
  }

  async countUnread(userId: string): Promise<number> {
    try {
      const rows = await this.db
        .select({ count: sql<number>`count(*)::int` })
        .from(messageMentions)
        .where(
          and(
            eq(messageMentions.mentionedUserId, userId),
            isNull(messageMentions.deletedAt),
            isNull(messageMentions.readAt),
          ),
        );

      return rows[0]?.count ?? 0;
    } catch (error) {
      throw new PersistenceException('Failed to count unread mentions', { cause: error });
    }
  }

  async findById(userId: string, id: string): Promise<MessageMentionRecord | null> {
    try {
      const rows = await this.db
        .select(mentionSelection)
        .from(messageMentions)
        .innerJoin(
          messages,
          and(
            eq(messages.chatId, messageMentions.chatId),
            eq(messages.id, messageMentions.messageId),
          ),
        )
        .where(
          and(
            eq(messageMentions.mentionedUserId, userId),
            eq(messageMentions.id, id),
            isNull(messageMentions.deletedAt),
          ),
        )
        .limit(1);

      return rows[0] ? this.mapper.toRecord(rows[0]) : null;
    } catch (error) {
      throw new PersistenceException('Failed to load mention', { cause: error });
    }
  }

  async markRead(userId: string, ids: readonly string[], now: Date): Promise<number> {
    if (ids.length === 0) {
      return 0;
    }

    try {
      const rows = await this.db
        .update(messageMentions)
        .set({ readAt: now })
        .where(
          and(
            inArray(messageMentions.id, [...ids]),
            eq(messageMentions.mentionedUserId, userId),
            isNull(messageMentions.deletedAt),
            isNull(messageMentions.readAt),
          ),
        )
        .returning({ id: messageMentions.id });

      return rows.length;
    } catch (error) {
      throw new PersistenceException('Failed to mark mentions read', { cause: error });
    }
  }
}
```

```ts
const MENTION_TOKEN = /(?<![\w@\/.])@([A-Za-z][A-Za-z0-9_]{4,31})(?![A-Za-z0-9_])/g;

/**
 * Extracts unique, lowercased usernames from a plain-text message body.
 * The grammar mirrors the `users.username` check constraint; the boundary
 * prevents email addresses and URL paths from producing mentions.
 */
@injectable()
export class MentionParser {
  parse(body: string): string[] {
    const names = new Set<string>();

    for (const match of body.matchAll(MENTION_TOKEN)) {
      const name = match[1];

      if (name !== undefined) {
        names.add(name.toLowerCase());
      }
    }

    return [...names];
  }
}
```

```ts
import { inject, injectable } from 'inversify';
import { CORE_TYPES } from '@/core/container/core.types.js';
import { NotFoundException } from '@/core/errors/http.error.js';
import type { UsernameReader } from '@/core/users/username.reader.js';
import type { MessageMentionRecord } from '@/modules/messages/logic/entities/message-mention-record.js';
import { MentionParser } from '@/modules/messages/logic/mention-parser.js';
import type { ChatMemberRepository } from '@/modules/messages/logic/ports/chat-member.repository.js';
import type {
  ListMentionsQuery,
  MessageMentionRepository,
} from '@/modules/messages/logic/ports/message-mention.repository.js';
import { MESSAGES_TYPES } from '@/modules/messages/messages.types.js';

/** Owns mention resolution, lifecycle, and inbox reads for the messages module. */
@injectable()
export class MentionService {
  private readonly parser = new MentionParser();

  constructor(
    @inject(MESSAGES_TYPES.MessageMentionRepository)
    private readonly repository: MessageMentionRepository,
    @inject(CORE_TYPES.UsernameReader) private readonly usernames: UsernameReader,
    @inject(MESSAGES_TYPES.ChatMemberRepository) private readonly members: ChatMemberRepository,
  ) {}

  async sync(chatId: string, messageId: string, body: string): Promise<void> {
    const names = this.parser.parse(body);

    const [memberships, resolved] = await Promise.all([
      this.members.listByChat(chatId),
      Promise.all(names.map((name) => this.usernames.findByUsername(name))),
    ]);

    const memberIds = new Set(
      memberships.filter((member) => member.leftAt === null).map((member) => member.userId),
    );
    const targets = resolved.filter(
      (id): id is string => id !== null && memberIds.has(id),
    );

    await this.repository.sync(chatId, messageId, [...new Set(targets)], new Date());
  }

  hideForMessage(chatId: string, messageId: string): Promise<void> {
    return this.repository.hideForMessage(chatId, messageId, new Date());
  }

  listForMessages(
    chatId: string,
    messageIds: readonly string[],
  ): Promise<Map<string, MessageMentionRecord[]>> {
    return this.repository.listForMessages(chatId, messageIds);
  }

  list(userId: string, query: ListMentionsQuery): Promise<MessageMentionRecord[]> {
    return this.repository.list(userId, query);
  }

  countUnread(userId: string): Promise<number> {
    return this.repository.countUnread(userId);
  }

  async markOne(userId: string, id: string): Promise<MessageMentionRecord> {
    const existing = await this.repository.findById(userId, id);

    if (!existing) {
      throw new NotFoundException('Mention not found');
    }

    await this.repository.markRead(userId, [id], new Date());

    return (await this.repository.findById(userId, id)) ?? existing;
  }

  async markMany(userId: string, ids: readonly string[]): Promise<number> {
    const unique = [...new Set(ids)].slice(0, 100);
    return this.repository.markRead(userId, unique, new Date());
  }
}
```

```ts
import type { Request, RequestHandler } from 'express';
import { inject, injectable } from 'inversify';
import { CORE_TYPES } from '@/core/container/core.types.js';
import { NotFoundException, UnauthorizedException } from '@/core/errors/http.error.js';
import type { ApiResponse } from '@/core/http/response/api-response.js';
import type { UserSummaryReader } from '@/core/users/user-summary.reader.js';
import type { MentionService } from '@/modules/messages/logic/mention.service.js';
import { MESSAGES_TYPES } from '@/modules/messages/messages.types.js';
import {
  listMentionsQuerySchema,
  mentionParamsSchema,
  readMentionsSchema,
} from '@/modules/messages/web/dto/message.schemas.js';

/** Request-scoped handlers for the caller's mention inbox. */
@injectable()
export class MentionController {
  constructor(
    @inject(MESSAGES_TYPES.MentionService) private readonly mentions: MentionService,
    @inject(CORE_TYPES.UserSummaryReader) private readonly users: UserSummaryReader,
    @inject(CORE_TYPES.ApiResponse) private readonly response: ApiResponse,
  ) {}

  list: RequestHandler = async (req, res) => {
    const userId = this.requireUser(req).id;
    const query = listMentionsQuerySchema.parse(req.query);
    const [records, unreadCount] = await Promise.all([
      this.mentions.list(userId, { limit: query.limit + 1, beforeId: query.cursor }),
      this.mentions.countUnread(userId),
    ]);
    const page = records.slice(0, query.limit);
    const nextCursor = records.length > query.limit ? (page.at(-1)?.id ?? null) : null;
    const summaries = await this.users.findSummaries([
      ...new Set(page.map((record) => record.mentionedByUserId)),
    ]);
    const byId = new Map(summaries.map((summary) => [summary.id, summary]));

    const items = page.map((record) => {
      const summary = byId.get(record.mentionedByUserId);

      if (!summary) {
        throw new NotFoundException('Mention sender not found');
      }

      return {
        id: record.id,
        chatId: record.chatId,
        messageId: record.messageId,
        createdAt: record.createdAt.toISOString(),
        readAt: record.readAt?.toISOString() ?? null,
        mentionedBy: {
          userId: summary.id,
          username: summary.username,
          displayName: summary.displayName,
          avatarKey: summary.avatarKey,
        },
      };
    });

    this.response.ok(res, { unreadCount, mentions: items }, { pagination: { nextCursor } });
  };

  readOne: RequestHandler = async (req, res) => {
    const userId = this.requireUser(req).id;
    const { mentionId } = mentionParamsSchema.parse(req.params);
    const record = await this.mentions.markOne(userId, mentionId);

    this.response.ok(res, {
      id: record.id,
      readAt: (record.readAt ?? new Date()).toISOString(),
    });
  };

  readMany: RequestHandler = async (req, res) => {
    const userId = this.requireUser(req).id;
    const { mentionIds } = readMentionsSchema.parse(req.body);

    this.response.ok(res, { marked: await this.mentions.markMany(userId, mentionIds) });
  };

  private requireUser(req: Request): Express.User {
    if (!(req.auth && req.isAuthenticated())) {
      throw new UnauthorizedException();
    }

    return req.user;
  }
}
```

```ts
    const context = await this.receipts.contextFor(message.chatId, userId);
    const views = await this.mentionViews(message.chatId, [message]);

  private async mentionViews(
    chatId: string,
    messages: readonly MessageRecord[],
  ): Promise<Map<string, MentionView[]>> {
    if (messages.length === 0) {
      return new Map();
    }

    const byMessage = await this.mentions.listForMessages(
      chatId,
      messages.map((message) => message.id),
    );
    const summaries = await this.users.findSummaries([
      ...new Set([...byMessage.values()].flat().map((record) => record.mentionedUserId)),
    ]);
    const summaryById = new Map(summaries.map((summary) => [summary.id, summary]));
    const result = new Map<string, MentionView[]>();

    for (const [messageId, records] of byMessage) {
      result.set(
        messageId,
        records.map((record) => {
          const summary: UserSummary | undefined = summaryById.get(record.mentionedUserId);

          if (!summary) {
            throw new NotFoundException('Mentioned user not found');
          }

          return {
            userId: summary.id,
            username: summary.username,
            displayName: summary.displayName,
          };
        }),
      );
    }

    return result;
  }
```

```markdown
### Mentions

`@username` tokens in cloud text messages resolve case-insensitively to users who are members of that chat. Unknown names, non-members, and names in email addresses or URLs remain plain text. Mentions are recomputed when a message is edited and hidden when it is deleted or self-destructs.

`GET /api/chats/mentions` returns `{ "unreadCount": 0, "mentions": [...] }` with cursor pagination under `meta.pagination`; no message body is included, so the client loads the message from history. Each inbox item identifies the message sender under `mentionedBy`. `POST /api/chats/mentions/:mentionId/read` marks one mention read and `POST /api/chats/mentions/read` accepts `{ "mentionIds": ["..."] }` with 1–100 ids. Message views include `mentions` with the resolved user's `userId`, `username`, and `displayName`. Push notifications for mentions are not part of this phase.
```
